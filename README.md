# speedtest
# Speed Test CLI

Консольный скрипт на Python: последовательно скачивает указанный URL 10 раз,
замеряет время каждого запроса, суммарный объём данных и печатает среднюю
скорость скачивания.

## Единицы измерения

Скорость выводится в **Mbit/s (мегабитах в секунду)**:

    speed = (bytes * 8) / elapsed_seconds / 1_000_000

Это стандартная единица, в которой провайдеры и speedtest-сервисы указывают
скорость интернета. Дополнительно печатается объём в байтах и MiB.

## Требования

- Python 3.10+ (используется синтаксис `tuple[float, int]` / `list[float]`;
  для 3.8–3.9 уберите аннотации вложенных типов).
- Внешние зависимости не нужны — только стандартная библиотека.

## Запуск

```bash
python speedtest.py https://speed.cloudflare.com/__down?bytes=10000000
